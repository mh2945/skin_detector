## 1. 문제의 정체 — 멜라닌과 헤모글로빈이 둘 다 얼굴을 붉게 만든다

| 색소 | 흡수 특성 |
|---|---|
| **멜라닌** | 파랑→빨강으로 매끄럽게 **단조 감소**. 피크 없음. |
| **oxy-Hb** | **542 / 577 nm 이중 피크**(Q-band) + 415 nm Soret. 초록을 강하게, 빨강을 거의 안 먹음. |

혈류가 늘면 G 가 R 대비 떨어져 붉어 보인다. 멜라닌이 늘면 B·G 가 떨어져 **역시** 붉/갈색이다.
**둘 다 a\* 를 올린다 — 이것이 교란의 정체다.** a\* 하나만 보면 구분할 수 없다.

## 2. 로그 밀도 — 왜 자기참조가 원리적으로 옳은가

선형 반사율 `R_c` 의 광학밀도 `D_c = −log₁₀(R_c)` 에서

```
D = c_m·v_m + c_h·v_h + D_0 + s·[1,1,1]
```

**음영·노출·거리·플래시 감쇠는 log-RGB 벡터를 [1,1,1] 방향으로만 움직인다.**
색소 변화는 `v_m`, `v_h` 방향으로 움직인다. → **[1,1,1] 을 죽이면 1차 조명 변동이 수학적으로 소거된다.**

가장 싸게 죽이는 방법이 채널 간 로그 비율이다:

```
e = D_G − D_R = log₁₀(R/G)      홍반 축
m = D_B − D_G = log₁₀(G/B)      멜라닌 축
```

### 실측 검증 (`test_color.py`)

| 교란 | 결과 |
|---|---|
| 전역 밝기 k배 (k=0.25~3.0) | max&#124;Δe&#124; < **1e-5** — float32 정밀도 한계. 정확히 소거 |
| **픽셀별** 음영 (0.4~1.4 랜덤) | max&#124;Δe&#124; < **1e-5** — 전역이 아니어도 소거 |
| 화이트밸런스 (채널 게인 1.18/0.91/1.33) | **std(Δe) < 1e-5**, 평균 +0.0969 → **순수 상수 오프셋** |
| 기준선 차감 후 | max&#124;Δd&#124; < **1e-5** — 조명색이 완전히 사라진다 |
| **포화** (max ≥ 1.0) | &#124;Δe&#124; > 0.05 — **불변성이 깨진다** |

> **로그 비율이 픽셀별 음영을 죽이고, 자기참조가 남은 상수 오프셋을 죽인다.**
> 마지막 줄은 버그가 아니라 물리다 — 그래서 품질 게이트가 포화 화소를 버린다.

**기각한 것들.** `YCbCr Cr` 은 **감마 인코딩** RGB 의 선형 결합이라 로그가 아니고
음영이 안 죽는다. 그늘진 볼에서 그냥 내려간다. `HSV H` 는 저채도에서 불안정하다.
빠른 근사로는 되지만 **측정은 아니다.**

## 3. 두 색소의 방향 벡터 — 실측

`data/spectra/hb_melanin_extinction.csv` + CIE 1931 CMF 근사 + sRGB 변환:

```
v_h (헤모글로빈) = (0.553, 1.000, 0.506)    G 최대  ← 542/577nm Q-band
v_m (멜라닌)     = (0.403, 0.552, 1.000)    B 최대, 피크 없이 단조 증가
```

(e, m) 평면에서의 이동:

| | Δe | Δm | 기울기 Δe/Δm |
|---|---|---|---|
| 헤모글로빈 | **+0.447** | **−0.494** | −0.91 |
| 멜라닌 | +0.149 | **+0.448** | +0.33 |

> **둘 다 e 를 올리지만 m 의 부호가 반대다.** 이것이 2차원 색소 평면이 작동하는 이유이고,
> 모반을 걸러낼 수 있는 유일한 근거다. 각 분리는 60° 이상이다.

### ⚠ 진피 광로장 가중이 없으면 이 결과가 뒤집힌다

oxy-Hb 의 415 nm Soret 밴드는 흡광계수가 Q-band 보다 **10배 크다.** 그대로 곱하면
`v_h = (0.211, 0.304, 1.000)` 이 나와 "헤모글로빈은 파랑을 가장 많이 먹는다"는
**물리적으로 틀린 결론**에 도달한다.

실제로는 415 nm 빛이 표피 산란·멜라닌 흡수에 막혀 **혈관이 있는 깊이까지 도달하지 못한다.**
`color.dermal_pathlength()` 가 이 사실을 시그모이드로 인코딩한다. 멜라닌은 표피에 있어
모든 파장이 닿으므로 이 가중을 적용하지 않는다.

이 구분이 없으면 §1 의 "구분자는 파랑 채널"이라는 명제 자체가 무너진다.

## 4. 주 지표 — 얼굴별 멜라닌 회귀 제거

```
ERI(x) = e(x) − (β·m(x) + α)
```

α, β 는 얼굴마다 피부 마스크 위에서 robust 회귀로 잡는다. 고정 벡터 투영이 아닌 이유는
고정 `v_m` 이 피부톤·기기·조명 SPD 에 따라 틀어지기 때문이다.

### ⚠ 자유 적합은 홍반 신호를 먹는다 — 두 가지 방식으로

**① G 채널 공유 노이즈.** `e = D_G − D_R` 과 `m = D_B − D_G` 는 G 를 공유한다.
G 의 노이즈가 e 에는 +1, m 에는 −1 로 들어가므로 **순수 노이즈만으로 β ≈ −0.5** 가 적합된다.
깨끗한 합성 피부에서 실측 β = **−0.41** 이었다.
→ **적합 전에 저역통과한다.** 제거 대상인 멜라닌 구배(태닝선·눈 주위 착색·광노화)는
원래 저주파이므로 잃는 것이 없다.

**② 부호.** 위 표에서 멜라닌의 기울기는 **+0.33**, 헤모글로빈은 **−0.91** 이다.
**음수 β 는 물리적으로 멜라닌일 수 없다.** 허용하면 회귀가 홍반을 "멜라닌"으로 오인해
통째로 빼버린다 — 실측에서 주입량을 늘릴수록 β 가 −0.41 → **−0.86** 으로 끌려가며
복원값이 오히려 **감소**했다.
→ **β 를 `[0, 0.6]` 으로 클램프한다.**

두 보정 후 합성 Δ 복원은 기울기 = 기대치(0.447) 대비 오차 15% 이내, **R² ≥ 0.99** 다.

## 5. 두 임상 타겟은 공간 주파수로 갈린다

```
diffuse(x) = lowpass(d)(x)        σ = 0.25·IPD    미만성 홍반
lesion(x)  = d(x) − lowpass(d)(x)                 개별 병변
```

**저역통과는 반드시 normalized convolution** — `blur(d·valid)/blur(valid)`.
그냥 `blur(d)` 를 쓰면 마스크된 화소(0)가 이웃을 끌어내려 눈·입술·머리카락 주변이
전부 가짜 저홍반이 된다. **가장 자주 틀리는 지점이다.**

### DoG 스케일 (정규 IPD 320 기준)

```
IPD 320px ↔ 63mm  →  1mm = 5.08px
구진 2~5mm → 반지름 5.1~12.7px → σ = r/√2 ∈ [3.6, 9.0]
4스케일: σ_k = 3.6 · 1.36^k  →  3.6, 4.9, 6.6, 9.0
```

박스 3회 근사의 실효 σ 오차는 **최대 ~4%** (3.6→3.46, 9.0→8.83, 80→83.1).
스케일 간 간격이 1.36배라 스케일 선택에는 영향이 없고 크기 추정치에만 편향으로 들어온다.
`test_measure.py` 가 이 상한을 5% 로 고정한다.

**DoG 응답은 진폭 단위로 되돌린다.** 정합 스케일에서의 이론 이득
`1/2 − 1/(1+k²) = 0.149` 로 나누면 응답 최대값이 곧 블롭 진폭(= `d` 와 같은 log₁₀ 단위)이 된다.
흔히 쓰는 σ² 곱셈을 하지 않는 이유는 그러면 `peak_min_d` 가 `d` 와 다른 단위가 되어
**임계값을 물리적으로 해석할 수 없기 때문**이다. 튜닝이 이 프로젝트의 본체이므로
임계값은 해석 가능해야 한다.

## 6. 정반사 — 물리로 잡는다

피부 정반사는 표면(Fresnel) 반사이고 **분광적으로 중립**이다. 피부색이 아니라 **광원색**을 띤다.
이색성 반사 모델에서 정반사는 모든 채널에 같은 양을 더한다.
→ 무광 피부에서 `min(R,G,B)` 는 낮은 B 를 따라가지만 정반사가 얹히면 함께 올라간다.
**`min(R,G,B)` 상승이 견고한 정반사 프록시다.**

> **보정이 아니라 마스크로만 쓴다.** specular-free image(`C − min(R,G,B)`)로 보정하고 싶어지지만
> 비율을 비선형으로 바꿔버린다.

## 7. 피부 판별 — 얼굴 자체에서 학습한다

하드코딩 YCbCr 피부색 박스는 쓰지 않는다. 피부톤이 조금만 벗어나면 무너진다.
대신 볼 중앙 고신뢰 패치에서 (e, m) 평면 2-D 가우시안을 적합하고 Mahalanobis > 3 을 기각한다.
자기참조라 모든 피부톤에서 자동 동작한다.

### ⚠ 공분산에 바닥이 없으면 이 게이트가 병변 자체를 잘라낸다

복색이 아주 균일한 얼굴에서는 적합된 가우시안이 임의로 좁아져 **실제 홍반이 분포 밖으로
밀려난다.** 실측에서 주입한 병변 4개가 전부 `skin=False` 가 되어 검출이 0이었다.
→ 각 축 표준편차에 하한(`chroma_min_sigma = 0.03`)을 둔다. 그 아래 차이는 어차피 노이즈 수준이다.

## 8. 반드시 지킬 것

1. **감마 선형화 필수.** 검정 근처 piecewise 구간을 단순 거듭제곱으로 근사하면
   채널별 상수항이 어긋나 자기참조가 깨진다.
